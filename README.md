# Кафе — приложение для заказа

## Суть приложения
Мобильное приложение для кафе. Пользователь просматривает меню,
добавляет блюда в корзину, меняет количество, видит итоговую сумму
и оформляет заказ.

## Технологический стек
- Язык: Dart
- Фреймворк: Flutter (Material 3)
- Управление состоянием: setState
- IDE: Visual Studio Code
- Контроль версий: Git, GitHub

## Запуск
```
flutter pub get
flutter run
```
